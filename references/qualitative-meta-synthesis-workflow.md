## Overview

Qualitative meta-synthesis integrates findings from multiple qualitative studies
to develop new conceptual understanding — not to aggregate frequencies. Core
methodologies: **Noblit & Hare's meta-ethnography** (1988), **thematic
synthesis** (Thomas & Harden, 2008), **critical interpretive synthesis**
(Dixon-Woods et al.), and **meta-aggregation** (JBI).

**Reporting:** **ENTREQ** (Tong et al., 2012) — 21 items. Confidence assessment:
**GRADE-CERQual** (Lewin et al., 2015, 2018).

**Critical principle:** Meta-synthesis produces *new* interpretations, not a
summary of what original authors said. The synthesizer's analytical role is
central and must be reflexively documented.

**Recommended architecture:** Plan-and-Execute with Evaluator-Optimizer
loops on translation and line-of-argument construction.

## Synthesis Method Selection

| Method | Best For | Output |
|--------|----------|--------|
| Meta-ethnography (Noblit & Hare) | Interpretive synthesis seeking new theory | Line-of-argument synthesis |
| Thematic synthesis (Thomas & Harden) | Policy-relevant, descriptive + analytical themes | Analytical themes |
| Critical interpretive synthesis | Complex, contested bodies of evidence | Synthesising argument |
| Meta-aggregation (JBI) | Decision-supportive, action-oriented | Categorized findings + recommendations |
| Meta-study (Paterson) | Theory, method, and data analysis across studies | Tri-component synthesis |
| Framework synthesis | Pre-existing conceptual framework available | Deductively mapped themes |

## Phase Architecture

```
Phase 1: Protocol and Method Choice (4 skills)
    ↓ QG1: Question justifies qualitative synthesis, method selected
Phase 2: Systematic Identification (4 skills)
    ↓ QG2: Purposive/comprehensive sampling strategy executed transparently
Phase 3: Quality Appraisal (2 skills)
    ↓ QG3: Appraisal applied without becoming an exclusion axe
Phase 4: Coding and Translation (5 skills)
    ↓ QG4: Reciprocal translation complete, refutations identified
Phase 5: Synthesis Construction (3 skills)
    ↓ QG5: Line-of-argument / themes developed with provenance
Phase 6: Confidence and Reporting (3 skills)
    ↓ QG6: CERQual applied per finding, ENTREQ complete
```

## Quality Gate Definitions

### QG1: Protocol → Identification

**Automated:**
- [ ] Question formulated via SPIDER or PEO
- [ ] Method selection justified against alternatives
- [ ] Reflexivity baseline document archived
- [ ] Protocol registered (PROSPERO where eligible, or OSF)

**Human Review:**
- [ ] Question is genuinely interpretive, not a thinly-framed effectiveness question

### QG2: Identification → Appraisal

**Automated:**
- [ ] Sampling strategy documented (comprehensive vs purposive)
- [ ] Qualitative study filter applied
- [ ] Flow diagram counts reconcile
- [ ] Rationale recorded for every excluded full-text

**Human Review:**
- [ ] Sample represents the conceptual breadth of the phenomenon

### QG3: Appraisal → Coding

**Automated:**
- [ ] Every included study has a QA rating
- [ ] Exclusion for quality documented with rationale
- [ ] Sensitivity analysis plan recorded

**Human Review:**
- [ ] Appraisal has not removed theoretically rich studies prematurely

### QG4: Coding → Synthesis

**Automated:**
- [ ] First-order quotes, second-order concepts, third-order codes distinct and tagged
- [ ] Translations tracked study-to-study (who translates into whom)
- [ ] Refutations identified and logged (not suppressed)

**Human Review:**
- [ ] Third-order codes genuinely go beyond restating original authors
- [ ] Translations preserve contextual meaning

### QG5: Synthesis → Confidence

**Automated:**
- [ ] Line of argument / analytical themes traceable to source codes
- [ ] Each finding shows contributing studies
- [ ] Visual synthesis diagram produced

**Human Review:**
- [ ] Synthesis offers new conceptual insight
- [ ] Refutations engaged, not sidelined

### QG6: Confidence → Delivery

**Automated:**
- [ ] CERQual rating per review finding (methodological limitations, coherence, adequacy, relevance)
- [ ] ENTREQ 21 items all addressed
- [ ] Reflexivity discussed in manuscript
- [ ] Quote attribution consistent (first-order quotes sourced)

**Human Review:**
- [ ] Confidence ratings defensible
- [ ] Limitations include synthesizer subjectivity

## Reciprocal Translation Protocol

Reciprocal translation is the engine of meta-ethnography. The translator asks:
*Can the concepts of study A be expressed in the language of study B, and vice versa?*

```json
{
  "translation_id": "T-014",
  "concept_a": {
    "label": "Moral distress",
    "source": "Jameton 1984 as cited in Study 03",
    "context": "Nurses unable to act on ethical judgment"
  },
  "concept_b": {
    "label": "Ethical residue",
    "source": "Study 07",
    "context": "Cumulative impact of unresolved moral events"
  },
  "translation": "reciprocal — Study 07 extends Jameton's concept temporally",
  "refutational": false,
  "synthesizer_note": "Both concepts trace to Nightingale's duty-of-care tradition; Study 07 is temporally cumulative whereas Jameton is event-based"
}
```

A translation table is produced before the line-of-argument synthesis. Both
reciprocal translations (concepts align) and refutational translations
(concepts conflict) must be documented.

## ENTREQ Reporting

The 21-item checklist is verified deterministically. Reference: Tong et al.
(2012) *BMC Med Res Methodol* 12:181.

Items the checker enforces:

| Item | Check |
|------|-------|
| 1 — Aim | Stated clearly |
| 2 — Synthesis methodology | Named and cited |
| 3 — Approach to searching | Purposive vs comprehensive stated |
| 5 — Search strategy | Reproducible detail |
| 8 — Quality assessment | Tool named, applied |
| 11 — Number of reviewers | Coders listed, agreement discussed |
| 13 — Software | Named (NVivo, ATLAS.ti, Dedoose, or manual) |
| 14 — Quotations | Represented with attribution |
| 16 — Derivation of themes | Inductive/deductive stated |
| 21 — Confidence in synthesis | CERQual or equivalent applied |

## CERQual Confidence Assessment

Each review finding is rated on four components and given an overall
confidence: High / Moderate / Low / Very Low.

| Component | Question |
|-----------|----------|
| Methodological limitations | Are included studies rigorously conducted? |
| Coherence | Is the finding supported by coherent data? |
| Adequacy | Is the quantity and richness of data supporting it sufficient? |
| Relevance | Do the data support the finding in the context of the review question? |

Each rating requires written justification. The manuscript's findings section
reports confidence alongside each finding, not only in an appendix.

## Common Failure Modes

| Failure | Cause | Prevention |
|---------|-------|------------|
| Summary of originals, not synthesis | Stays at second-order level | QG4 requires distinct third-order codes |
| Positivist framing | Effect-size / frequency language in qualitative synthesis | Reasoning zone uses interpretive register |
| Quote cherry-picking | Favoured quotes chosen without contextual scan | Traceability to full transcripts or first-order logs |
| Refutations suppressed | Contradictory findings ignored | QG4 requires refutation log |
| Reflexivity absent | Synthesizer position not documented | Baseline doc required at QG1 |
| Over-integration | Heterogeneous concepts forced into one theme | Refutational mapping catches forced fits |
| Thin synthesis | Many descriptive themes, no analytical move | QG5 requires analytical theme development |
| CERQual applied as checklist, not judgment | Tick-box confidence ratings | Written rationale per rating |
| Confusion of method | Claims meta-ethnography but does thematic synthesis | QG1 method selection is binding; deviations documented |
| Sample conflates quantitative studies | Mixed-methods papers included without qual-strand focus | Extraction limited to qualitative strand |
